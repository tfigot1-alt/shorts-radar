# 쇼츠레이더

YouTube Data API v3로 직접 데이터를 모으는 쇼츠 채널 발굴 도구입니다. 구독, 결제, 기능 제한이 전혀 없습니다.

## 바로 사용

👉 **https://tfigot1-alt.github.io/shorts-radar/** — 설치 없이 브라우저에서 바로 사용 (설정에서 본인 API 키 입력)

`main` 브랜치에 push하면 GitHub Actions가 `public` 폴더를 자동으로 배포합니다.

## 내 컴퓨터에서 실행

1. [Node.js](https://nodejs.org) 설치 (이미 있으면 생략)
2. `start.bat` 더블클릭 (또는 터미널에서 `node server.js`)
3. 브라우저에서 http://localhost:5178 접속 → **설정**에서 API 키 입력

> `index.html`을 파일로 바로 열면 썸네일 위 재생(YouTube 임베드)이 막힙니다. 꼭 서버로 실행하세요.

## API 키 발급 (무료)

1. https://console.cloud.google.com 에서 프로젝트 생성
2. 'YouTube Data API v3' 사용 설정
3. 사용자 인증 정보 → API 키 만들기
4. (권장) 키 제한 → HTTP 리퍼러 `https://tfigot1-alt.github.io/shorts-radar/*`, `http://localhost:5178/*`

하루 10,000 유닛 무료입니다. 검색 1회는 100 유닛이고, 채널·영상 조회는 50개당 1 유닛입니다.

## 기능

| 탭 | 내용 |
|---|---|
| 대시보드 | 급상승 레이더(24시간/3일/7일), 신생 떡상(90일 이내), 꿀통 지수 TOP, 오늘의 한 방, 주간 결산 |
| 데일리 떡상 | 최근 24시간~7일 쇼츠를 국가, 카테고리, 키워드, 최소 조회수로 필터링 |
| 채널 탐색 | 키워드 검색 또는 추적 DB 전체를 구독자, 채널 나이, 꿀통 지수로 필터링. URL이나 @핸들을 넣으면 바로 분석 |
| Top 300 | 국가별 최근 7일 쇼츠 Top 300 또는 YouTube 공식 인기 차트(최대 200) |
| 채널 상세 | 성장 곡선, 일일 증감, 일·월 예상 수익, 평소 대비 배수 배지, 메모, 찜, 벤치마크 |
| 내 활동 | 즐겨찾기(찜 시점 대비 성장), 벤치마크 비교(최대 6개, 내 채널 지정), 북마크 영상, 메모, 최근 본 채널 |

- **썸네일 위에서 바로 재생**: 마우스를 올리면 음소거 상태로 재생됩니다.
- **시계열 데이터**: 앱이 켜져 있으면 6시간마다(설정에서 변경 가능) 추적 채널 통계를 자동으로 모읍니다. 오래 쓸수록 급상승과 성장 곡선이 정확해집니다.
- **꿀통 지수(0~100)**: 구독자 대비 조회수 35%, 일 조회 속도 35%, 업로드 빈도 15%, 채널 나이 15%를 합친 점수입니다.
- **예상 수익**: 일 조회수 × RPM입니다. 설정의 쇼츠 RPM 값으로 계산하는 추정치입니다.

## 데이터

모든 데이터는 브라우저 localStorage에 저장됩니다. 설정에서 백업 JSON을 내보내거나 불러올 수 있습니다.

## 참고

- 미리 수집된 데이터 없이 **사용하면서 직접 쌓습니다**. 처음에는 대시보드의 '🌱 채널 씨앗 수집'을 누르세요.
- YouTube 공개 API는 쇼츠에 쓰인 음원 정보를 제공하지 않아 BGM 차트는 없습니다.
